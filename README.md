# FuelApp ⛽

Aplicação Android, desenvolvida em Kotlin, que calcula o custo de combustível de uma viagem.

## Funcionalidades

- Introdução da distância da viagem, do consumo médio do veículo e do preço do combustível
- Cálculo do custo total da viagem

## Tecnologias

- Kotlin
- Android SDK (Views em XML)
- AndroidX

## Como executar

1. Clonar o repositório:
   ```bash
   git clone https://github.com/<utilizador>/<repositorio>.git
   ```
2. Abrir o projeto no Android Studio.
3. Aguardar a sincronização do Gradle.
4. Executar num emulador ou num dispositivo físico.
